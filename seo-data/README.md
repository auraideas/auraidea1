# UAE SEO Search-Intent Library

This directory contains the 5,000 natural Arabic, English, and mixed-language search queries prepared for Aura Ideas, an academic-support website serving students and researchers in the United Arab Emirates.

## How to use this library

The phrases are a research and content-planning asset. They should not be pasted into page footers, hidden text, meta keywords, or one-page keyword lists. Group similar phrases by search intent and assign each group to an existing service page or an editorial article that genuinely answers the query.

Prioritize pages for research-topic selection, methodology and proposal guidance, literature reviews, statistical-analysis support, academic proofreading and translation, thesis formatting, graduation projects, and UAE-local queries where the local context changes the answer. Keep one primary intent per page, use natural language, add internal links, and consolidate overlapping URLs.

## Publication rule

Only publish a phrase when the page provides a useful, original answer or service explanation. Do not create doorway pages for every emirate or university, and do not promise academic misconduct or undisclosed ghostwriting. The library is stored for editorial planning and should not itself be submitted as an indexable page.

## Files

- `keywords_uae_5000.csv`: 5,000 records with phrase, language, intent, stage, service, specialty, local context, and human angle.
- `keywords_uae_5000.jsonl`: the same records in JSON Lines format for editorial tooling.
- `summary.md`: distribution and quality notes.
